# AXON Library

AXON의 프로그램 배포 정보와 Voice 샘플을 한곳에서 확인하는 통합 웹 페이지입니다.

## 구성

- **프로그램**: AXON Studio, AXON StoryLab 최신 버전과 GitHub Release 연결
- **Voice**: TypeCast / ElevenLabs 음성 92개 재생, 검색, voice ID 복사, MP3 다운로드

## 실행

```powershell
npm install
npm run dev
```

## 검증

```powershell
npm run build
npm test
```
