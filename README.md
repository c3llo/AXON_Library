# AXON Library

AXON의 프로그램 배포 정보, Voice 샘플, 추천 이미지 스타일을 한곳에서 확인하는 통합 웹 페이지입니다.

## 구성

- **프로그램**: AXON Studio, AXON StoryLab 최신 버전과 GitHub Release 연결
- **Voice**: TypeCast / ElevenLabs 음성 92개 재생, 검색, voice ID 복사, MP3 다운로드
- **이미지**: AXON Studio 추천 그림체 8개 미리보기와 전체 스타일 프롬프트 복사

## 실행

```powershell
npm install
npm run dev
```

## 검증

```powershell
npm run build
npm test
```
